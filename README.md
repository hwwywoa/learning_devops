# learning_devops

## Description

This is a devops-learning project with simple python app and some docker stuff.
Used Python version: Python 3.11.9

## How to run it?

1. Clone repository

2. Setup Python virtual environment (venv):
    python -m venv venv   

3. Activate venv:
    .\venv\Scripts\activate

4. Install dependences:
    pip install -r requirements.txt

5. Run app:
    python .\flask\main.py
